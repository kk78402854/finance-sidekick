验收目标：每条业务链路都能在真实库里跑通，并且出错时给出可执行的中文提示。

---

```bash

uv run -m app.main

# 客服
cd finance-assistant && python main.py

python -c "from assistant.engine.builder import build_engine; e = build_engine(); print('engine ok')"
```

## 4. 联调脚本

### 4.1 一次完整贷款闭环

```text
用户：我想申请贷款
助手：请告诉我贷款类型（消费贷/经营贷/现金贷/分期贷）
用户：消费贷
助手：贷款金额是多少？
用户：五万
助手：期限多少个月？
用户：24
助手：贷款用途是？
用户：装修
助手：已为您提交申请，申请号 LAP2026...，当前状态 processing。
```

随后到中台走审批：

```powershell
# 管理员登录 → 审批通过
POST /api/v1/risk/loan-applications/{application_no}/approve
POST /api/v1/loans/contracts       # 生成合同
POST /api/v1/loans/contracts/{contract_no}/sign
POST /api/v1/loans/disburse        # 全额放款
```

放款后：额度冻结金额归零、已用额度增加、合同状态 `active`。

### 4.2 切换 / 恢复 / 取消

```text
用户：我要申请贷款
助手：请告诉我贷款类型……
用户：先帮我查下余额
助手：好的，现在把贷款申请暂停，开始执行账户查询……
用户：继续
助手：好的，继续刚才的贷款申请……请告诉我贷款类型……
用户：算了，不办了
助手：好的，取消该操作。
```

### 4.3 对象消息

```text
① 发送 object(type=account, id=真实账户号)     → 澄清“已收到该账户，想办理什么？”
② 发送 text “查最近一周流水”                    → 直接问开始日期（账户号已自动填）
③ 发送 text “2026-11-01”                        → 回复流水，说明总笔数
```

## 5. 异常与边界

| 场景 | 期望 |
| --- | --- |
| 中台未启动 | 回复“暂时无法查询”，不 500 |
| 客户无额度 | “您当前没有可用授信额度” |
| 金额 > 可用额度 | 明确提示可用额度，不提交 |
| 金额/期限超产品区间 | 提示区间，不提交 |
| 额度状态非 active | 提示不可用，不提交 |
| 交易区间无数据 | “该时间段没有交易记录” |
| 账户不属于该客户 | 中台 404，回复“未找到该账户” |
| 工单缺 `X-Operator-No` | 中台 403，回复“工单服务暂不可用” |
| LLM 超时 / 401 | 返回兜底话术，不抛 500 |
| LLM 输出非法 JSON | `TurnPlan.from_dict` 失败 → 澄清 |
| 同一 `sender_id` 并发两次 | 状态最终一致，不重复建单（`request_no` 幂等） |
| 空文本 / 空对象 | 澄清追问 |

## 6. 风险与规避

| 风险 | 表现 | 规避 |
| --- | --- | --- |
| LLM 幻觉 | 编造产品、利率、流程名 | 事实只来自接口/FAQ/RAG；流程名与意图限定在清单内；Validator 用配置和状态核对 |
| 意图歧义 | “你好，帮我查余额”被当闲聊 | Prompt 固定判断顺序（已有任务 → 新任务 → 知识 → 闲聊）并给示例 |
| 槽位丢失 | 多轮后金额/期限丢失 | 状态整段存库；每轮 load→改→save；切换任务用 paused 保留 |
| 行业字段不匹配 | 枚举中文/英文混用 | 统一在 Action 内映射，Prompt 只产出用户语言 |
| 接口契约变化 | 字段改名导致取不到值 | 所有访问收口在 `finance_client`；字段缺失用 `.get()` 兜底 |
| 数据初始化影响 | `init_db.py` DROP 库 | 演练前确认库名；生产禁用脚本 |
| 鉴权配置错 | 403 渠道/员工不可用 | 启动前用第 5 节 SQL 校验渠道与员工 |
| 密钥泄露 | `.env` 被提交 | `.gitignore` 排除；示例只写占位符 |
| 并发写状态 | 同一用户双开 | 演示阶段限制单端；生产需加乐观锁 |
