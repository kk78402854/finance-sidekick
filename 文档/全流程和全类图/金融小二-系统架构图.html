TaskHandler 业务流程

  • FlowExecutor 步骤机：Start → Collect → Action → Response → End
  • FlowCatalog：7 条 YAML 流程，条件跳转 / fallback
  • ActionRegistry：6 个自定义动作，pkgutil 自动注册
  • ActionRunner → 中台接口，Jinja2 渲染回复

KnowledgeHandler 知识问答

  • 19 类知识意图，按意图选择 Provider
  • FAQ 20 条种子数据 + 可配置 RAG 检索
  • Prompt 统一拼装，引用资料作答
  • 检索为空 → 确定性兜底，不编造

DialogueState 会话状态

  • sessions / turns 多轮记录
  • active task / slots 流程上下文

  • 整段 JSON 持久化 MySQL

Clarify / ChitChat 兜底

  • 计划无效 → 澄清追问
